How it works

Physics first, machine learning for what the physics gets wrong.

  1. Physics. Kubelka-Munk theory turns pigment concentrations into a reflectance curve, 400 to 700 nm. Colorimetry turns the curve into CIELAB under each light.
  2. Learned correction. An ensemble of neural networks learns what Kubelka-Munk misses from 14,000 historical lab panels. Disagreement between ensemble members is the model's uncertainty.
  3. Fine-tuning. When a new pigment lot arrives, one calibration panel per pigment re-fits each pigment's strength. Nothing else is retrained.
  4. Search. A second network reads the target's reflectance curve and shortlists the five most likely pigments. Concentrations are optimised for every combination of one to three of them at once. If nothing passes, the shortlist widens before the search gives up.
  5. Robust choice. Each candidate is scored across model members and pigment-lot variation. Only recipes likely to pass under all four lights are eligible.

FirstShot is a portfolio project. The lab is simulated and carbon figures are illustrative indices; production use would plug in measured pigment data and supplier carbon footprints.
